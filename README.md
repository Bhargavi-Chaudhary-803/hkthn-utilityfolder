# hkthn-utilityfolder

A complete library of components & boilerplate code for hackathons: reusable UI pieces, starter templates, helper scripts, seed data, design assets, and pitch material, so you spend your 24–48 hours on the idea instead of the setup.

## What's inside

| Folder | Purpose |
|---|---|
| `components/` | Reusable, drop-in UI components |
| `templates/` | Project starters / boilerplate to clone and build on |
| `snippets/` | Small copy-paste code blocks for common tasks |
| `scripts/` | Automation and setup scripts |
| `seed-data/` | Sample datasets for demos and testing |
| `design/` | Design assets and guidelines |
| `pitch/` | Pitch deck and demo-day material |

See [`QUICKSTART.md`](./QUICKSTART.md) for setup.

## Quick start

```bash
git clone https://github.com/Bhargavi-Chaudhary-803/hkthn-utilityfolder.git
cd hkthn-utilityfolder
```

1. Pick a starter from `templates/` and copy it into your project.
2. Drop in what you need from `components/` and `snippets/`.
3. Load demo content from `seed-data/` so your app never looks empty on stage.
4. Use `scripts/` to automate repetitive setup.
5. Build your pitch from `pitch/`.

## Usage

Copy what you need; nothing here is meant to be installed as a package. Treat each folder as a shelf: take the piece, adapt it, move on.

## Contributing

Found a component or snippet that saved you time at a hackathon? Open a PR and add it to the matching folder with a one-line description.
